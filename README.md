# Pro Rugby Player Roadmap

## 概要

このリポジトリは、息子が将来的に「プロラグビー選手」を目指すための長期育成ロードマップを管理するための上位プロジェクトである。

本リポジトリでは、マンダラートの最初の9枠を起点として、育成全体の領域、記録方針、下位プロジェクトとの関係を整理する。

## 目的

- 最上位目標を明確にする
- マンダラートの最初の9枠を定義する
- 各育成領域の目的と記録方針を整理する
- フィジカル偏重を防ぎ、育成全体のバランスを保つ
- 測定可能なデータは早期に記録し、将来の分析可能性を高める
- 下位プロジェクトとの関係を明確にする

## 現時点の位置づけ

このプロジェクトは、以下の下位プロジェクトより上位に位置する。

- `junior-rugby-development-platform`
- `Togo-physical-training`

## 重要な考え方

- 各ドメインの重要度に単純な優劣をつけない
- 測定可能なものは早めに記録する
- ただし、記録することと評価モデル化することは分ける
- 数値化できない領域も、観察・振り返りの対象にする
- マンダラートは固定ではなく、運用しながら更新する
