# First 9 Cells Definition

## 1. 本資料の目的

本資料は、`mandalart_v0_1.md` で定義した最初の9枠について、各領域の目的、含めるもの、含めないもの、記録方針、将来の評価モデル化方針を整理する。

この定義は固定ではなく、運用しながら更新する。

本資料では、各領域の重要度に単純な優劣をつけない。  
また、測定可能なものだけを重視せず、数値化しにくい能力や観察対象も、長期育成に必要な要素として扱う。

---

## 2. 中央目標

## 2.1 プロラグビー選手

### 目的

長期的に高い水準で成長し続け、将来的にプロラグビー選手として活動できる状態を目指す。

ここでいう「プロラグビー選手」とは、単に身体能力や競技スキルが高い選手ではなく、技術、戦術理解、メンタル、生活習慣、学習力、コミュニケーション、人間性、自己管理能力を含めて、継続的に成長できる選手を指す。

### 含めるもの

- 競技能力
- 身体能力
- 技術
- 戦術理解
- メンタル
- 生活習慣
- 学習力
- コミュニケーション
- 人間性
- 継続力
- 自己調整能力
- コーチャビリティ
- チームの中で価値を発揮する力

### 含めないもの

- 親の期待だけで決める短期目標
- 本人の主体性を無視した管理
- 測定値だけで選手価値を決めること
- フィジカル能力だけで将来性を判断すること
- 大人の理想像を一方的に押し付けること

## 3.1 フィジカル

### 目的

ラグビーを高いレベルでプレーするための身体的土台を育てる。

フィジカルは、走力やパワーだけでなく、身体操作、柔軟性、視覚機能、コーディネーション、怪我予防に関わる身体要素も含む。  
ただし、フィジカル測定値だけで選手の可能性を判断しない。

### 含めるもの

- 走力
- パワー
- 持久力
- 方向転換
- 上半身パワー
- 反発・ばね能力
- 柔軟性
- 可動域
- 体組成
- 怪我予防に関わる身体要素
- 視覚機能・スポーツビジョン
- 身体リテラシー
- コーディネーション
- バランス
- 姿勢制御
- 基本動作能力
- 身体操作能力

### 含めないもの

- フィジカル測定値だけで選手の可能性を判断すること
- 短期的な数値改善だけを目的にすること
- 体格や体重だけで優劣を決めること
- 成長段階を無視した比較
- 怪我リスクを無視した高負荷トレーニング

### 今すぐ記録するもの

- 10m / 30m sprint
- CMJ
- RSI
- COD
- Medicine Ball Throw
- Yo-Yo IR1
- RSA
- 身長
- 体重
- InBody
- 通常視力
- 視力検査結果
- 眼鏡・コンタクト使用状況
- 痛みや疲労のメモ
- 苦手な動き
- フォーム上の気づき

### 将来評価モデル化するもの

- U14 / U16 / U18 / 18+ との比較
- 体組成とフィジカル変化の関係
- 柔軟性・可動域
- 動作品質
- 動体視力
- 深視力
- 眼球運動
- 周辺視野
- スポーツビジョン
- 身体リテラシー
- コーディネーション
- バランス・姿勢制御
- 怪我予防能力

### 関連する下位プロジェクト

- `Togo-physical-training`
- `junior-rugby-development-platform`

## 3.2 ラグビースキル

### 目的

試合で実際に使える個人スキルを育てる。

ラグビースキルは、単なる技術練習ではなく、試合状況の中で発揮できる実用的なスキルとして扱う。

### 含めるもの

- パス
- キャッチ
- キック
- タックル
- ボールキャリー
- ブレイクダウン
- ラック
- 1対1
- サポートプレー
- コンタクトスキル
- ハンドリング
- 空間把握を伴うスキル
- 視覚情報を使ったスキル発揮

### 含めないもの

- 単なる練習メニューの消化
- 試合状況と切り離した技術評価
- 成功・失敗だけを見た評価
- 指導者や親の主観だけによる断定

### 今すぐ記録するもの

- 試合・練習で目立ったスキル課題
- 成功したプレー
- 失敗したプレー
- コーチからの指摘
- 本人の感想
- キャッチやキックでの見え方・距離感の課題
- タックルやコンタクトでの姿勢課題

### 将来評価モデル化するもの

- スキル別チェックリスト
- 試合映像レビュー
- ポジション別スキル評価
- キャッチ・パス・キックの安定性
- コンタクト局面での技術評価
- スキルと視覚機能・認知の関係

### 関連する下位プロジェクト

- `junior-rugby-development-platform`
- 将来の match review / skill log

## 3.3 戦術・認知

### 目的

試合中に正しい判断を行い、チームの中で効果的にプレーできる力を育てる。

戦術・認知は、単に戦術を知っていることではなく、試合中に情報を見て、予測し、判断し、実行する力として扱う。

### 含めるもの

- ポジショニング
- スペース認知
- 予測
- 判断速度
- サポート判断
- ディフェンス判断
- ラグビーIQ
- 試合理解
- 知覚・認知能力
- 意思決定
- 実行機能
- 注意
- 情報処理速度
- ワーキングメモリ
- 認知柔軟性
- 周辺視野
- 視覚情報の認知
- 視覚情報からの予測・判断

### 含めないもの

- 結果だけを見た後付け評価
- 大人の戦術理解をそのまま押し付けること
- 判断ミスだけを責めること
- 指示通りに動くことだけを良い判断とすること

### 今すぐ記録するもの

- 試合中の良い判断
- 判断が遅れた場面
- ポジショニングの課題
- 試合後の本人の振り返り
- 見えていたもの
- 見えていなかったもの
- 予測が当たった場面
- 判断に迷った場面
- 周囲を見られていた場面
- 周囲が見えていなかった場面

### 将来評価モデル化するもの

- 試合映像レビュー
- 判断場面の分類
- ポジション別認知課題
- 視野の広さと判断の関係
- 視覚情報からの予測・判断
- 認知負荷が高い場面での判断
- 実行機能とプレー判断の関係
- ラグビーIQ評価

### 関連する下位プロジェクト

- `junior-rugby-development-platform`

## 3.4 メンタル

メンタルは、性格を評価するためではなく、競技・練習・失敗・挑戦にどう向き合うかを観察し、支援するために扱う。

### 含めるもの

- 自信
- 集中
- 失敗耐性
- 競争心
- 勝負強さ
- 緊張への対応
- 感情のコントロール
- レジリエンス
- ストレス対処
- 挑戦する姿勢
- 不調から戻る力
- 試合前後の気持ちの整理

### 含めないもの

- 性格を一方的に評価すること
- 医療的・心理的診断
- 数値だけで心の状態を決めること
- 弱さを責めること
- 親や指導者の理想に合わせて感情を抑え込ませること

### 今すぐ記録するもの

- 練習や試合への態度
- 失敗後の反応
- 挑戦した場面
- 消極的だった場面
- 本人の言葉
- 緊張した場面
- 悔しがった場面
- 切り替えられた場面
- 自分から挑戦した場面
- 不調でも前向きに取り組めた場面

### 将来評価モデル化するもの

- 主観的コンディション
- 試合前後の振り返り
- メンタルチェックリスト
- レジリエンス
- 感情調整
- プレッシャー場面での行動
- 失敗後の回復プロセス

### 関連する下位プロジェクト

- 将来の reflection log
- `junior-rugby-development-platform`

生活・回復は、競技能力を支える土台として扱う。  
管理しすぎることではなく、本人が自分の状態に気づき、整える力を育てることを重視する。

- 食事や体重に対する過度なプレッシャー

## 3.7 人間性・習慣

### 目的

素直に学び、主体的に行動し、長期的に信頼され、成長し続ける選手としての土台を育てる。

人間性・習慣は、競技者としてだけでなく、人として信頼され、継続的に努力できるための基礎として扱う。

### 含めるもの

- 素直さ / coachability
- 継続力
- 礼儀
- 責任感
- 主体性
- 自己管理
- 約束を守る力
- 感謝
- 誠実さ
- 自己調整能力
- 目標設定
- 振り返り
- 修正する力
- 学び続ける姿勢

### 含めないもの

- 親の価値観だけを押し付けること
- 過度な人格評価
- 一時的な失敗で決めつけること
- 大人に従うことだけを「素直さ」とすること
- 自分の意見を持たないことを良いこととすること

### 素直さ / coachability の定義

本プロジェクトでいう「素直さ」は、単に大人の言うことを何でも聞くことではない。

以下のような、成長のために助言を受け止め、試し、修正できる力として扱う。

- 指摘を一度受け止める
- 自分の間違いを認める
- 試してみる
- 修正する
- 感謝する
- 学び続ける
- 感情的に反発しすぎない
- 良いものを吸収する

### 今すぐ記録するもの

- 自分から行動したこと
- 継続できたこと
- 約束を守れたこと
- 生活面での課題
- 親子で話し合ったこと
- 指摘を受け止めて修正したこと
- 素直に試してみたこと
- 感情的に反発せず受け入れられたこと
- 自分で目標を立てたこと
- 振り返って改善したこと

### 将来評価モデル化するもの

- 習慣チェック
- 自己管理ログ
- 目標設定と振り返り
- コーチャビリティ

## 4. 横断サブドメインの扱い

一部の能力は、単一の領域に固定せず、複数領域にまたがる横断サブドメインとして扱う。

## 4.1 視覚機能・スポーツビジョン

通常視力、動体視力、深視力、周辺視野、眼球運動などは、単一ドメインに固定しない。

### 主な関連領域

- フィジカル
- 戦術・認知
- ラグビースキル
- 生活・回復

### 扱い方

- 通常視力や眼のコンディションは、フィジカル領域の補助データとして記録する
- 周辺視野、視覚情報の認知、予測、判断は、戦術・認知領域と関連づける
- キャッチ、キック、タックル、空間把握への応用は、ラグビースキル領域と関連づける
- 眼精疲労や見え方の変化は、生活・回復領域とも関連づける

## 4.2 知覚・認知・意思決定

試合中に情報を受け取り、状況を読み、予測し、判断する力を扱う。

### 主な関連領域

- 戦術・認知
- ラグビースキル
- コミュニケーション
- 学習・思考力

### 扱い方

- 試合中の判断やポジショニングは、戦術・認知に記録する
- 技術実行に関わる認知は、ラグビースキルにも関連づける
- 味方との情報共有は、コミュニケーションにも関連づける
- 振り返りや言語化は、学習・思考力にも関連づける

## 4.3 実行機能

注意、抑制、ワーキングメモリ、認知柔軟性などを扱う。

### 主な関連領域

- 戦術・認知
- 学習・思考力
- 人間性・習慣

### 扱い方

- 試合中の注意や切り替えは、戦術・認知に記録する
- 学習時の集中や理解は、学習・思考力に記録する
- 習慣化や自己管理は、人間性・習慣に関連づける

## 4.4 身体リテラシー・コーディネーション

走る、跳ぶ、投げる、捕る、止まる、方向を変える、バランスを取るなど、多様な基本動作と身体操作を扱う。

### 主な関連領域

- フィジカル
- ラグビースキル
- 動作品質

### 扱い方

- 基本動作や身体操作は、フィジカル領域に記録する
- ボール操作や接触を伴う動きは、ラグビースキルにも関連づける
- 動きの質やフォームは、将来的に動作品質として整理する

## 4.5 睡眠・栄養・回復リテラシー

成長、トレーニング適応、怪我予防を支える生活能力として扱う。

### 主な関連領域

- 生活・回復
- フィジカル
- 人間性・習慣

### 扱い方

- 睡眠、栄養、疲労、休養は、生活・回復に記録する
- 体組成や測定値への影響は、フィジカルとも関連づける
- 自分で整える力は、人間性・習慣にも関連づける

## 4.6 自己調整能力

目標設定、実行、振り返り、修正、継続、感情調整を扱う。

### 主な関連領域

- 人間性・習慣
- メンタル
- 学習・思考力
- 生活・回復

### 扱い方

- 行動や習慣の改善は、人間性・習慣に記録する
- 感情の調整は、メンタルに記録する
- 学習の振り返りは、学習・思考力に記録する
- 生活の調整は、生活・回復に記録する

## 5. 記録と評価モデルの分離

本プロジェクトでは、記録することと評価モデル化することを分ける。

### 5.1 Record

事実、測定値、観察メモを保存する段階。

例:

- テスト結果
- 視力検査結果
- 睡眠時間
- 練習量
- 試合中の気づき
- コーチからの指摘
- 本人の言葉

### 5.2 Review

記録を定期的に振り返る段階。

例:

- 月次レビュー
- 四半期レビュー
- 試合後レビュー
- 測定後レビュー

### 5.3 Model

評価モデル化、スコア化、分析対象にする段階。

例:

- フィジカルスコア
- 成長トレンド
- 学習習慣の傾向
- 判断力評価
- 生活習慣と体調の関係

### 5.4 基本方針

- 今すぐ記録できるものは、低負荷で記録を始める
- 記録を始めても、すぐに評価モデル化しない
- 数値化できないものは、観察メモとして扱う
- 将来分析できるように、日付、場面、対象、メモを残す
- 入力負荷が高い記録は継続できないため、最小限から始める

---

## 6. 運用上の注意

- この分類は仮説であり、固定しない
- 複数領域にまたがる記録は、無理に1つに絞らない
- まずは記録の置き場を決めるために使う
- 評価やスコア化は慎重に進める
- 本人の主体性を損なわない
- 親の管理が強くなりすぎないように注意する
- 測定しやすいものだけを重視しない
- フィジカル偏重を避ける
- 定期的にマンダラート全体のバランスを見直す
