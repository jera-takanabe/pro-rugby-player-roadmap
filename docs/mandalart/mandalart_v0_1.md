# Mandalart v0.1

## 1. 本資料の目的

本資料は、最上位目標である「プロラグビー選手」を中心に置き、その実現に必要な最初の8領域を仮説として定義する。
また、単にプロラグビー選手を目指すということではなく、その過程で自分の人生を生き抜く力、楽しむ力を培うものとする。

この9枠は固定ではなく、今後の運用・観察・対話を通じて更新する。

## 2. 最上位目標

**プロラグビー選手**

ここでいう「プロラグビー選手」とは、単に競技能力だけでなく、身体、技術、戦術理解、精神面、生活習慣、学習力、コミュニケーション、人間性を含めて、長期的に高い水準で成長し続けられる選手を指す。

## 3. 最初の9枠 v0.1

|---|---|---|
| フィジカル | ラグビースキル | 戦術・認知 |
| 生活・回復 | プロラグビー選手 | メンタル |
| 学習・思考力 | 人間性・習慣 | コミュニケーション |

## 4. 8領域の初期定義

| 領域 | 初期定義 |
|---|---|
| フィジカル | 走力、パワー、持久力、方向転換、柔軟性、体組成など、競技を支える身体能力 |
| ラグビースキル | パス、キャッチ、キック、タックル、ブレイクダウン、ボールキャリーなどの競技技術 |
| 戦術・認知 | ポジショニング、スペース認知、判断、予測、ラグビーIQ、試合理解 |
| メンタル | 自信、集中、失敗耐性、競争心、勝負強さ、感情のコントロール |
| 生活・回復 | 睡眠、栄養、疲労、怪我予防、日常活動、練習負荷管理 |
| 学習・思考力 | 学力、読解力、英語、理解力、言語化、考える力 |
| 人間性・習慣 | 継続力、礼儀、責任感、主体性、自己管理、約束を守る力 |
| コミュニケーション | チーム内会話、質問力、伝える力、聞く力、リーダーシップ、協調性 |

## 5. 設計原則

- 各領域の重要度に単純な優劣をつけない
- 測定しやすい領域だけを重視しない
- 測定できるものは早期に記録を始める
- ただし、記録することと評価モデル化することは分ける
- 数値化できない領域も観察・振り返り対象にする
- フィジカル偏重を避け、全体バランスを定期的に確認する
- マンダラートは仮説として運用し、必要に応じて更新する

## 6. 今後の詳細化方針

各領域について、今後以下を定義する。

1. 目的
2. 含めるもの
3. 含めないもの
4. 今すぐ記録するもの
5. 将来評価モデル化するもの
6. 関連する下位プロジェクト
7. 月次・四半期で確認する観点
